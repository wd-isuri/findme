# FindMe 🔍

**AI-Powered Lost & Found System**

FindMe is a web-based platform designed to help university and hostel students report, search, and recover lost items. The system uses AI to identify potential matches between lost and found item reports and notifies users when a possible match is found.

## Features

* 📝 Report lost items
* 📦 Report found items
* 🔎 Search and filter items
* 🤖 AI-powered lost and found item matching
* 🔔 Notifications for potential matches
* 👤 User account management
* ✅ Mark items as recovered
